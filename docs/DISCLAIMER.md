# 内容合规与脱敏说明

本仓库用于求职展示，内容遵循以下原则。

## 1. 脱敏范围

以下内容**不会**出现在本仓库中：

| 类别 | 示例 |
|:--|:--|
| 源码 | 企业项目全部源码、内部脚本 |
| 网络与凭据 | 内网 IP、SSH / 机器人密码、API Key、Token |
| 设备信息 | 设备序列号、固件私有信息、机载目录结构 |
| 商业资料 | 公司内部文档、图纸、未公开数据 |
| 第三方链接 | 内部协作文档、私有网盘、供应商交流群 |

## 3. 数字与指标

- 所有指标均来自实际测试或项目技术文档。
- 涉及多团队贡献的指标，均标注归属（如「团队 / 项目结果」），不据为己有。
- 未完成的验证步骤明确标注为「未执行 / 未通过审批」，不包装为已完成。
